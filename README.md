## 📌 Project Overview
The **OLA Ride Data Analysis Project** analyzes ride-booking data to understand business performance, customer behavior, and operational efficiency.  
The project uses **SQL** for data analysis and **Power BI** for data visualization to convert raw data into meaningful business insights.

---

## ❓ Problem Statement
OLA generates a large volume of ride-booking data every day, including bookings, cancellations, customers, drivers, vehicle types, payments, and ratings.  
Without proper analysis, it becomes difficult to identify booking trends, cancellation reasons, revenue drivers, and service quality issues.  

This project solves the problem by analyzing data using **SQL** and presenting insights through an interactive **Power BI dashboard**.

---

<h2><a class="anchor" id="Project Objectives"></a>Project Objectives</h2>

- Analyze successful, cancelled, and incomplete rides  
- Identify key reasons for ride cancellations  
- Study customer booking behavior and top customers  
- Evaluate vehicle type performance  
- Analyze customer and driver ratings  
- Examine payment method usage  
- Understand revenue trends  
- Create an interactive Power BI dashboard  

---

## 🗂 Dataset Description
The dataset includes:
- Booking ID  
- Customer ID  
- Vehicle Type  
- Ride Distance  
- Booking Status  
- Cancellation Reason  
- Payment Method  
- Booking Value  
- Customer Rating  
- Driver Rating

## 🧠 SQL Analysis (Key Questions)
- Successful bookings analysis  
- Average ride distance by vehicle type  
- Customer and driver cancellations  
- Top 5 customers by number of rides  
- Payment method analysis (UPI, Cash, Card)  
- Customer and driver ratings analysis  
- Total booking value calculation  
- Incomplete rides with reasons  

All SQL queries are available in the `SQL/` folder.

---

## 📊 Power BI Dashboard
The Power BI dashboard provides insights on:
- Ride volume over time  
- Booking status distribution  
- Revenue by payment method  
- Top customers  
- Vehicle performance  
- Customer vs driver ratings  

The dashboard helps stakeholders quickly understand trends and issues.

---

## 🔍 Key Insights
- A small number of customers contribute a large share of revenue  
- Digital payments (especially UPI) are widely preferred  
- Certain vehicle types perform better in ratings and ride distance  
- Cancellations highlight operational improvement areas  

---

## ✅ Conclusion
This project demonstrates how **SQL and Power BI** can be used together to analyze real-world ride data and generate actionable insights.  
It supports data-driven decision-making, improves operational efficiency, and enhances customer experience.
